📊 THREE-PIPELINE ARCHITECTURE
================================================================================

┌─────────────────────────────────────────────────────────────────────────┐
│                        PIPELINE 1: INITIAL TRAINING                      │
├─────────────────────────────────────────────────────────────────────────┤
│  Input: Historical Data (18 months)                                     │
│  Process: Train SARIMAX model with exogenous variables                  │
│  Output: Initial model → models/sarimax_initial_18months.pkl           │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│                     PIPELINE 2: DAILY INFERENCE                         │
├─────────────────────────────────────────────────────────────────────────┤
│  For each day in forecast period:                                       │
│    1. Use expanding window (includes all data up to yesterday)          │
│    2. Retrain model with expanded data                                  │
│    3. Predict next day                                                   │
│    4. Store prediction                                                   │
│  Process: 30 daily predictions (one month)                              │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│                    PIPELINE 3: MONTHLY RETRAINING                       │
├─────────────────────────────────────────────────────────────────────────┤
│  After completing 1 month:                                              │
│    1. Expand training window by 1 month                                 │
│    2. Retrain model with 19 months of data                             │
│    3. Save updated model → models/sarimax_month_N_19months.pkl         │
│  Then return to Pipeline 2 for next month                              │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
                            [Repeat for all months]

📈 PERFORMANCE METRICS
================================================================================

Model Evaluation Metrics (Automatically Calculated):

┌─────────────────────────────────────────────────────────────────────────┐
│ MAE  (Mean Absolute Error)                                              │
│ → Average absolute difference between predicted and actual values       │
│ → Lower is better                                                        │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ RMSE (Root Mean Squared Error)                                          │
│ → Square root of average squared differences                            │
│ → Penalizes larger errors more heavily                                  │
│ → Lower is better                                                        │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ MAPE (Mean Absolute Percentage Error)                                   │
│ → Average percentage difference between predicted and actual            │
│ → Expressed as percentage                                               │
│ → Lower is better (< 10% is excellent)                                 │
└─────────────────────────────────────────────────────────────────────────┘


================================================================================
🛠️ CUSTOMIZATION OPTIONS
================================================================================

In main.py, edit CONFIG dictionary:

CONFIG = {
    'TRAIN_WINDOW_MONTHS': 18,      # Change training window size
    'FORECAST_HORIZON_DAYS': 1,     # Change forecast steps
    'SARIMAX_ORDER': (1, 1, 1),     # Change ARIMA parameters
    'SEASONAL_ORDER': (1, 1, 1, 7), # Change seasonality (7=weekly)
    'OUTPUT_DIR': './outputs/',      # Change output location
    'MODEL_DIR': './models/',        # Change model storage location
}

Advanced Customizations:
• Modify data cleaning rules in load_and_prepare_data()
• Add/remove exogenous variables in exog_var_names list
• Adjust lag days: lag_days = [1, 7, 14, 30]
• Change aggregation levels in aggregate_predictions()
• Add custom API endpoints in Flask app
